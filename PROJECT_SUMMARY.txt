--------------------------------------------------------------------------------
DATABASE MODELS
--------------------------------------------------------------------------------

1. Student Model
   - roll_number (CharField, unique)
   - first_name (CharField)
   - last_name (CharField)
   - email (EmailField, unique)
   - phone (CharField)
   - department (CharField)
   - year (IntegerField)
   - photo (ImageField) - for face recognition
   - face_encoding (TextField) - stored facial features
   - is_active (BooleanField)
   - created_at, updated_at (DateTimeField)

2. Attendance Model
   - student (ForeignKey to Student)
   - date (DateField)
   - time (TimeField)
   - status (CharField: present/absent/late)
   - marked_by (CharField)
   - remarks (TextField)
   - created_at (DateTimeField)
   - Unique constraint: (student, date)

3. Course Model
   - code (CharField, unique)
   - name (CharField)
   - description (TextField)
   - department (CharField)
   - students (ManyToManyField to Student)
   - created_at (DateTimeField)

HOW TO GET STARTED
--------------------------------------------------------------------------------

1. Install dependencies:
   pip install -r requirements.txt

2. Run migrations:
   python manage.py migrate

3. Create admin user:
   python manage.py createsuperuser

4. Generate sample data:
   python manage.py populate_sample_data --students 10

5. Run the server:
   python manage.py runserver

6. Access the application:
   http://localhost:8000

7. (Optional) Install face_recognition:
   See FACE_RECOGNITION_GUIDE.md for detailed instructions
