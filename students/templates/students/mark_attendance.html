Face Recognition Attendance

Camera Setup
Face Recognition Setup Required

To enable face recognition, you need to install the face_recognition library: 

pip install face-recognition

Note: This library requires dlib and cmake to be installed on your system.

For Ubuntu/Debian: 

sudo apt-get install cmake
sudo apt-get install libopenblas-dev liblapack-dev
pip install dlib
pip install face-recognition

For macOS: 

brew install cmake
pip install dlib
pip install face-recognition

Camera Preview

Camera will appear here after face_recognition is installed

How it works:
  1. Install the face_recognition library using the commands above
  2. Allow camera access when prompted
  3. Position your face in front of the camera
  4. The system will automatically detect and match your face
  5. Attendance will be marked automatically
